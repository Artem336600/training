# training

GitHub-репозиторий со схемой `gitflow` и дополнительной веткой `beta`.

## Ветки

- `main` — продакшен-ветка.
- `beta` — предрелизная ветка для стабилизации и проверки.
- `develop` — основная ветка разработки.

## Поток работы

1. Новые задачи создаются из `develop` в ветках `feature/*`.
2. Когда набор изменений готов к проверке, `develop` вливается в `beta`.
3. После проверки `beta` вливается в `main`.
4. Срочные исправления создаются из `main` в ветках `hotfix/*` и затем возвращаются в `main`, `beta` и `develop`.

Подробности по процессу находятся в [docs/gitflow.md](docs/gitflow.md).
